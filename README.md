# Ecem Temizlik — Web Site Demo

Ecem Temizlik (Antakya) için hazırlanmış, mobil uyumlu statik web sitesi demosu.

## İçerik

- `index.html` — sayfa yapısı ve Türkçe içerikler
- `style.css` — renkler, düzen, responsive tasarım ve mobil menü stilleri
- `script.js` — mobil menü ve otomatik footer yılı
- `assets/ecem-temizlik-logo.png` — sağlanan firma logosu

## GitHub Pages üzerinde yayınlama

1. Bu klasördeki dosyaları bir GitHub deposunun kök dizinine yükleyin.
2. Depoda **Settings → Pages** bölümünü açın.
3. **Deploy from a branch** seçin, `main` dalını ve `/(root)` klasörünü belirtip kaydedin.
4. GitHub Pages adresi hazır olduğunda site bağlantısını müşterinizle paylaşabilirsiniz.
